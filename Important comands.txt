Docker commands
> docker version    --Check docker version

#Comamnd to build the docker image from Dockerfile. -t => tag
Syntax 	> docker build . -t <dockerUsername>/<imageName>:<version>
	> docker build . -t kumarsujay1994/accounts:easybytes1


 
> docker images		#To List all the images
> docker rmi <imageId>  #To delete the image


# To inspect any docker image and see the image details
Syntax :  docker inspect  <imageID>
	> docker inspect  0a63aa899386

#To run the docker container with the docker image. -p => port
Syntax  > docker run -p <Host Port>:<Container Port> <imagename:tag>
	> docker run -p 8080:8080 kumarsujay1994/accounts:easybytes1


#To run docker container with specific profile. -e => environment (same as above)

Syntax  > docker run -e SPRING_PROFILES_ACTIVE=<profileName> -p <hostPort>:<containerPort> <imagename:tag>
	> docker run -e SPRING_PROFILES_ACTIVE=docker -p 8080:8080 kumarsujay1994/accounts:easybytes1



> docker ps		# To display the containers currently running 
> docker ps -a		# To display all the containers. -a => all


> docker start <containerId>	 	# To start already created container
> docker stop <containerId>       	# To stop already created container
> docker rm <containerId>        	# To delete the container.
> docker pause <containerId>        	# To pause the container.
> docker unpause <containerId>
> docker restart <containerId>
> docker logs <containerId>		# Check container logs
> docker logs -f <containerId>		# Check container logs and follow the logs
> docker container prune		# To delete the stopper container all at once
> docker login -u kumarsujay1994    	# To login to docker repo
> docker exec -it <containerId> sh	# To open shell inside a running container and execute command

#Steps to generate docker image using Google Jib

1) on pom.xml add below plugin.
	     <plugin>
                <groupId>com.google.cloud.tools</groupId>
                <artifactId>jib-maven-plugin</artifactId>
                <version>3.5.2</version>
                <configuration>
                    <to>
                        <image>kumarsujay1994/${project.artifactId}:easybytes1</image>
                    </to>
                </configuration>
            </plugin>

2) Build the image
	> mvn compile jib:dockerBuild

3) Run the docker image
	> docker run -e SPRING_PROFILES_ACTIVE=docker -p 9000:9000 kumarsujay1994/cards:easybytes1

> docker compose start		#To Start the stopped containers created from docker compose
> docker compose stop		#To Stop the running containers created from docker compose
